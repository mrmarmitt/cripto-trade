# Roadmap — CTrade

## Propósito

Este documento registra **features futuras e evoluções planejadas** que não fazem parte do escopo atual mas foram identificadas durante o processo de design. Serve como backlog arquitetural para garantir que decisões de hoje não bloqueiem necessidades de amanhã.

## Escopo

- Cross-Exchange: suporte a Runners operando em múltiplas exchanges simultaneamente, soma de margem entre exchanges, prevenção de double counting
- Evoluções identificadas durante o design que foram deliberadamente postergadas

## Relação com outros documentos

- **Blueprint (BLUEPRINT_V9.md):** As features futuras devem ser compatíveis com a arquitetura definida
- **Implementation Guide:** Quando uma feature do roadmap for priorizada, suas decisões técnicas entram no Implementation Guide
